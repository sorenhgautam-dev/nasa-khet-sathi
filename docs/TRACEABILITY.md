# Where does this number come from?

Every number and data-driven word the site shows (`site/index.html`, `site/js/app.js`, `site/js/how.js`), screen by screen in the order a visitor meets them, traced back to its dataset. Values are the demo field's on 2026-11-14, with the rule switches as committed (`gauge_calibration`, `paddy_losses` and `field_capacity_measured` off). The key below explains the short names used in the tables. Cells marked **Finding** are gaps a judge could find; they are collected in the last table.

## Key

| Short name | Meaning |
|---|---|
| F, story, words | `site/data/fields/demo.json`, `site/data/story.json`, `site/data/words.json` |
| Code paths | No folder prefix means under `pipeline/` (e.g. `plans/score.py`). `scripts/` and `robot/` paths start at the repo root |
| `[step]` | A step name in `scripts/run_field.py` |
| TWIN | The field twin: `twin/season.py: simulate` (FAO-56 bucket, `twin/soil_water.py`), `twin/yield_.py: harvest_pct` (FAO-33) and `plans/simulate.py: yearly` (a year's harvest = the mean of its crops), called through `plans/twin_options.py: replay` |
| TWIN DATA | `data/clean/demo/weather.parquet` [weather] (`fetch/weather.py: build`, with `correct_gpm_break` and `twin/bias.py: build_correction`), `data/clean/demo/soilgrids.parquet` and `config/crops.json` |
| TWIN DATA: rain | GPM IMERG V07: Final daily (GPM_3IMERGDF) to Sep 2025, Late (GPM_3IMERGDL) for Oct–Dec 2025. Rain from 2017 on is scaled back to its 2001–2016 level |
| TWIN DATA: weather | NASA POWER daily API v2.10.3 (MERRA-2 weather, CERES sun), temperatures corrected to GHCN-Daily NP000444540 (Kathmandu Airport) |
| TWIN DATA: soil and crops | ISRIC SoilGrids 2.0; FAO-56 Tables 11, 12 and 22; Ky from FAO-33/66 (rice and lentil use an assumed Ky of 1.0) |
| TWIN RULES | The rules.yaml keys `curve_numbers`, `bare_soil`, `kc_climate`, `season_dates`, `paddy_rainfed`, `paddy_rice`, `ky_assumed`, `replay`, `water_source_unknown` and `gpm_series.correction` |
| DHM-SCALED | The same run on rain version `dhm` (`twin/inputs.py: with_rain, dhm_factors`): DHM Bhaktapur's 1991–2020 monthly normals (`config/dhm_normals_1991_2020.csv`; rule `gpm_series.dhm_scaling`), read from `data/checks/demo/rain_dhm/` [plans_dhm]. It is the low edge of every range |
| Status | The row of `data/checks/demo/scorecard.json` (its key in brackets); "–" means the scorecard has no row for it |
| Fixed words | Text in `pipeline/words/screens.json`, published by `export/build_words.py: build_words`. Listed only where it states a fact |
